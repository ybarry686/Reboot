# User Flow

## High-level experience

Reboot is designed to let people discover, evaluate, and book recovery services with minimal friction.

- A visitor opens the site and begins with a search or category selection.
- The application returns nearby recovery studios, sorts by distance, and highlights relevant service offerings.
- If the user has a specific goal, the app can surface a short recommendation to help narrow the choices.

## Core journeys

### Discovery

Users can quickly scan studios, compare descriptions and ratings, and identify options that match their recovery needs. The interface encourages exploration with search terms, service categories, and local context.

### Authentication and personalization

Users can create an account, authenticate securely, and save their preferences. Logged-in users can maintain a profile and access personalized features such as saved favorites and booking history.

### Favorites and return visits

The app supports bookmarking studios so users can easily return to preferred providers. Favorite studios are grouped in one place, making it faster to compare top choices or rebook a trusted location.

### Booking

Users can select a studio, review available services, and submit a booking request. The system captures the appointment details cleanly and confirms that the request has been recorded.

### Booking management

Users can review their booked sessions and cancel if their plans change. This keeps the workflow complete from discovery through post-booking management.

### Data growth and catalog extension

Authorized users can import new studio listings from an external business search source. This enables the catalog to grow organically and keeps the studio inventory fresh.

## Why this flow works

- It keeps the experience simple and focused on core tasks.
- Guests can discover studios without friction, while authenticated users gain access to persistent workflows.
- The flow is easy to extend with more advanced booking availability, provider confirmations, or mobile apps in the future.
